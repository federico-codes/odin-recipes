# Odin Recipes

This project is part of The Odin Project's Foundations course.

## About the Project

A simple recipe website built using HTML. The website includes a homepage with links to individual recipe pages containing descriptions, ingredients, and cooking instructions.

## Skills Practiced

- HTML boilerplate and document structure
- Headings and paragraphs
- Lists and links
- Images
- Git and GitHub version control
